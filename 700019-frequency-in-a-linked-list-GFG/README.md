# [Frequency in a Linked List](https://www.geeksforgeeks.org/problems/occurence-of-an-integer-in-a-linked-list/1)
## Easy
Given a singly linked list and a key, count the number of occurrences of the given key in the linked list.
Examples:
Input: head: 1-&gt;2-&gt;1-&gt;2-&gt;1-&gt;3-&gt;1, key = 1Output: 4
Explanation: 1 appears 4 times.&nbsp;
Input: head: 1-&gt;2-&gt;1-&gt;2-&gt;1, key = 3Output: 0
Explanation: 3 appears 0 times.
Constraints:1 ≤ number of nodes, key ≤ 1051 ≤ data of node ≤ 105
